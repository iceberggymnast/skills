# CS 진도 — 지식 보강 원장

`cs-drill` 스킬이 쓰고 읽는다. **이해 부채 원장(`comprehension-debt.md`)과 분리한다** — 그쪽은 "AI가 쓴 코드를 설명하는가"를 재고 여기는 "안 배운 것을 배웠는가"를 잰다. 섞으면 분포가 두 지표의 혼합이 되어 어느 쪽도 못 읽는다.

**커리큘럼이 여기 있는 이유**: 진도와 같은 자리에 있어야 고칠 때 한 파일만 열면 된다. 스킬 조문에 박으면 목록을 바꿀 때마다 스킬을 건드리게 된다.

> **아래 목록은 초안이다.** 빼거나 더하거나 순서를 바꿔도 된다. 게임 클라이언트에서 실제로 묻는 것을 앞에 뒀지만, 전 범위를 고른 선택이라 뒤쪽 영역도 남겼다.

## 복습 간격

실작업이 이 개념들을 다시 만나게 해주지 않으므로, 재노출은 이 표가 만든다.

| 시점 | 다음 `due` |
|---|---|
| 첫 설명을 들음 (`학습함`) | +3일 |
| 1회차 통과 | +14일 |
| 2회차 통과 | `닫힘` — due 없음 |
| 판별점을 못 짚음 | `학습함`으로 되돌리고 +3일 |

**통과 조건은 판별점을 스스로 짚는 것이다.** 설명을 다시 읽어서 납득한 것은 통과가 아니다 — `comprehension-debt.md`와 같은 규칙이다.
